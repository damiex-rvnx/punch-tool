Clock-Bot
Crew Clock Reminder

An automatic push notification system that reminds field crews exactly when to clock in and out for lunch and dinner — even with their phone locked and in their pocket.

📱 iPhone & Android 🔔 Background notifications ⚡ No app to download (Android) 💰 $10/month total
The Problem It Solves

Missed clock-ins cost money — on both sides

Field crews are busy. When it's time to clock out for lunch they're often mid-task, and the reminder slips their mind. Late or missed punches mean payroll corrections, supervisor follow-ups, and potential labor compliance issues. Clock-Bot eliminates that by sending automatic, time-sensitive notifications directly to each crew member's phone — no apps to open, no timers to set manually.

What the Crew Does Each Morning — Under 2 Minutes
1

Open Clock-Bot on their phone

Saved to their home screen — looks and feels like an app. No App Store download required (Android). No login needed.

2

Enter their start time

Type in the time they clocked in — e.g. 7:30 AM. Can be set the night before if the schedule is known.

3

Pick their lunch and dinner hour marks

Choose "4h 30m" for lunch = clock out 4.5 hours after start. The exact time is shown instantly. Toggle dinner off for short days.

4

Tap "Set Reminders" — done for the day

Phone goes in their pocket. The server handles everything else. No need to keep the app open.

5

Notifications arrive automatically

A heads-up fires a few minutes before each break, followed by the clock-out alert, then a clock-back-in reminder after the break ends.

Works on a locked, sleeping phone — even in a pocket with no screen interaction.

Data Flow — Step by Step
A

Crew member taps "Set Reminders"

The app on their phone calculates the exact times for each notification and sends them — along with a push subscription token — to the Cloudflare server over a secure (HTTPS) connection.

B

Server saves the schedule

Cloudflare stores the schedule in its key-value database with a 48-hour expiry. Nothing else is stored — no personal information, no location, no name.

C

The cron timer fires every 60 seconds

Cloudflare's built-in scheduler wakes the server every minute. It checks every stored schedule and compares each notification time to the current time. If a notification is due (within a 90-second window), it fires.

D

Delivery route depends on device type

iPhone: The server posts a message to ntfy.sh using the crew member's unique topic ID. ntfy.sh relays it through Apple's APNs servers to the ntfy app on their phone — which shows the notification even when the phone is asleep.

Android: The server sends an encrypted Web Push message directly to the crew member's browser subscription endpoint. The browser's background service wakes and displays the notification.

E

Fired notifications are removed from the schedule

Once a notification fires, it's removed from the stored schedule. When all notifications for the day have fired, the schedule entry is deleted entirely from the server — ahead of the 48-hour automatic expiry.

Security & Reliability

🔐 Encrypted end-to-end

All communication between devices and the server uses HTTPS. Push notification payloads are encrypted using the Web Push standard (AES-128-GCM) — only the recipient's device can decrypt them.

🌍 Globally distributed

Cloudflare Workers runs in 300+ data centers worldwide. Requests are handled by the nearest location, keeping latency extremely low regardless of where the crew is working.

⏱️ 60-second precision

The cron timer fires every minute. Notifications have a 90-second delivery window, so they can arrive within 0–90 seconds of the scheduled time under normal network conditions.

♻️ Self-cleaning

All schedules auto-expire after 48 hours with no manual cleanup required. The server never accumulates stale data from crew members who don't use the app on a given day.

Frequently Asked Questions
Does every crew member need to create an account anywhere?
No accounts needed at all. On Android there's zero registration. On iPhone they install the free ntfy app and enter one personal code — no email, no password, no sign-up.
What if a crew member's schedule changes day to day?
They open Clock-Bot, change their start time or hour mark, and tap "Set Reminders" again. Takes under a minute. The new schedule automatically replaces the old one.
Does it work without cell service?
An internet connection is needed briefly when tapping "Set Reminders" to upload the schedule. After that, delivery is handled by the server — so if the phone loses signal after setup and regains it before a notification fires, the notification will be delivered. For locations with no signal all day, the app cannot guarantee delivery.
Can it notify the entire crew at the same time?
Each crew member sets their own start time since they may clock in at different times. Notifications are personal per device. If a crew starts together and someone needs to broadcast a reminder, that's a supervisor function — this tool is for individual automation.
What happens if the server is down?
Cloudflare Workers has 99.99% uptime globally. In the very unlikely event of an outage, the app has a local fallback using the phone's own timer — so reminders still fire as long as the app process is alive in memory.
Does it require IT or a software vendor?
No vendor contract, no enterprise license, no IT infrastructure. Clock-Bot is built and maintained in-house. The only external services are Cloudflare and ntfy.sh, both managed via simple web dashboards.
Can this scale to more crew members?
Yes — the $10/month cost stays flat regardless of crew size. The system can handle hundreds of concurrent schedules at no additional cost.
Is there a way to see who has set their reminders?
Currently the tool is anonymous by design (no names stored). If usage tracking becomes a requirement, that can be added — but it would require crew members to identify themselves in the app, which adds friction to the workflow.
